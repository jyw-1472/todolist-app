## 공통 컴포넌트

### 헤더 / 상단 네비게이션 바

로그인 후 모든 보호 라우트에서 표시된다. 로고(앱 이름)와 로그아웃 버튼을 포함한다.

```
┌────────────────────────────────────────┐
│  TodoList          [로그아웃]          │
└────────────────────────────────────────┘
```

### 하단 탭 바 (모바일)

로그인 후 하단에 고정되며 주요 화면 간 이동을 담당한다.

```
┌────────────────────────────────────────┐
│  [할일목록]  [카테고리]  [프로필]      │
│     ●            ○          ○          │
└────────────────────────────────────────┘
```

- `●` 활성 탭, `○` 비활성 탭
- 라우트 매핑: `/` → 할일목록, `/categories` → 카테고리, `/profile` → 프로필

### 공통 모달 구조

오버레이 배경(░)과 중앙 정렬된 모달 컨테이너로 구성된다. ESC 키 및 배경 클릭으로 닫힌다(삭제·탈퇴 확인 모달은 배경 클릭 닫힘 비활성화 권장).

```
░░░║  모달 제목                 × ║░░░░░
░░░╠══════════════════════════════╣░░░░░
░░░║                              ║░░░░░
░░░║  (모달 내용 영역)            ║░░░░░
```

## 1. 회원가입 페이지 (SignupPage)

**시나리오:** S-01 | **UC:** UC-01 | **FE Task:** FE-10, FE-11
**API:** `POST /api/auth/signup`

```
│  [____________________________________]│
│                                        │
│  비밀번호                              │

│                                        │
```

## 2. 로그인 페이지 (LoginPage)

**시나리오:** S-02 | **UC:** UC-02 | **FE Task:** FE-10, FE-11
**API:** `POST /api/auth/login`

### 화면 설명

가입된 사용자가 이메일과 비밀번호를 입력해 인증하는 화면이다. 성공 시 Access Token + Refresh Token을 Zustand 메모리에 저장하고 할일 목록 화면으로 이동한다. 페이지 새로고침 시 토큰이 소멸되어 재로그인이 필요하다(의도된 동작).

### 기본 상태

```
┌────────────────────────────────────────┐
│                                        │
│            TodoList 로그인             │
│                                        │
│  이메일                                │
│  [____________________________________]│
│                                        │
│  비밀번호                              │
│  [____________________________________]│
│                                        │
│                                        │
│         [          로그인         ]    │
│                                        │
│    계정이 없으신가요?  회원가입 →      │
│                                        │
└────────────────────────────────────────┘
```

### 에러 상태 (인증 실패 — UNAUTHORIZED 401)

```
┌────────────────────────────────────────┐
│                                        │
│            TodoList 로그인             │
│                                        │
│  이메일                                │
│  [user@example.com__________________ ] │
│                                        │
│  비밀번호                              │
│  [************************************]│
│                                        │
│  ⚠ 이메일 또는 비밀번호가             │
│    올바르지 않습니다.                  │
│                                        │
│         [          로그인         ]    │
│                                        │
│    계정이 없으신가요?  회원가입 →      │
│                                        │
└────────────────────────────────────────┘
```

### 세션 만료 안내 상태

토큰 갱신(S-12) 실패 후 자동으로 로그인 화면으로 이동했을 때 표시한다.

```
┌────────────────────────────────────────┐
│                                        │
│            TodoList 로그인             │
│                                        │
│  ┌──────────────────────────────────┐  │
│  │ ⚠ 세션이 만료되었습니다.         │  │
│  │   다시 로그인해 주세요.          │  │
│  └──────────────────────────────────┘  │
│                                        │
│  이메일                                │
│  [____________________________________]│
│  비밀번호                              │
│  [____________________________________]│
│                                        │
│         [          로그인         ]    │
│                                        │
└────────────────────────────────────────┘
```

### 화면 전환 흐름

```
[SignupPage] → [LoginPage] → [TodoListPage]  (로그인 성공)
(직접 접근)  → [LoginPage] → [TodoListPage]  (로그인 성공)
[LoginPage]  → [SignupPage]                  (회원가입 링크)
```

### 주요 인터랙션

| 인터랙션 | 동작 |
|----------|------|
| 로그인 버튼 클릭 | POST /api/auth/login → 성공 시 Zustand setTokens() + setUser() |
| 로그인 성공 | /로 이동 (TodoListPage) |
| 인증 실패 | ⚠ 에러 메시지 표시 |
| 회원가입 링크 | /signup으로 이동 |
| 이미 로그인 상태에서 /login 접근 | /로 리다이렉트 |

## 3. 할일 목록 페이지 (TodoListPage)

**시나리오:** S-04~S-08 | **UC:** UC-04~UC-08 | **FE Task:** FE-13, FE-14
**API:** `GET /api/todos`, `PATCH /api/todos/:id/complete`

### 화면 설명

로그인한 사용자의 할일 목록을 표시하는 메인 화면이다. 카테고리, 완료 여부, 기간 필터를 지원하며, 기본 정렬은 종료 예정일 오름차순이다. 할일 추가(+) 버튼으로 등록 모달을 열고, 각 카드에서 완료 토글, 수정, 삭제 작업을 수행한다.

### 3-1. 기본 상태 (할일 있음)

```
┌────────────────────────────────────────┐
│  TodoList                [로그아웃]    │
├────────────────────────────────────────┤
│  할일 목록                             │
│                                        │
│  ┌── 필터 ───────────────────────────┐ │
│  │ 카테고리: [전체 ▼]               │ │
│  │ 완료여부: [전체 ▼]               │ │
│  │ 기간: [시작일______] ~ [종료일__] │ │
│  └───────────────────────────────────┘ │
│                                        │
│  ┌─────────────────────────────────┐   │
│  │ ☐  팀 미팅 자료 준비            │   │
│  │    📁 업무  |  📅 2026-05-15    │   │
│  │    ○ 미완료          ✏️  🗑️   │   │
│  └─────────────────────────────────┘   │
```

## 8. 프로필 페이지 (ProfilePage)

**시나리오:** S-03, S-13 | **UC:** UC-03, UC-13 | **FE Task:** FE-16
**API:** `GET /api/users/me`, `PATCH /api/users/me`, `DELETE /api/users/me`

### 화면 설명

로그인한 사용자의 개인정보(이름, 비밀번호)를 수정하는 화면이다. 화면 진입 시 `GET /api/users/me`로 현재 이름을 불러와 미리 채운다. 이름 변경과 비밀번호 변경 섹션이 분리되어 있다. 하단에 회원 탈퇴 섹션이 위치한다.

### 기본 상태

```
┌────────────────────────────────────────┐
│  TodoList                [로그아웃]    │
├────────────────────────────────────────┤
│  프로필                                │
│                                        │
│  ── 이름 변경 ────────────────────── │
│  현재 이름                             │
│  [김민준______________________________]│
│                      [  이름 변경  ]  │
│                                        │
│  ── 비밀번호 변경 ─────────────────── │
│  현재 비밀번호                         │
│  [____________________________________]│
│                                        │
│  새 비밀번호                           │
│  [____________________________________]│
│                                        │
│  새 비밀번호 확인                      │
│  [____________________________________]│
│                      [비밀번호 변경]  │
│                                        │

│         [ 회원 탈퇴 ]                 │
│                                        │
├────────────────────────────────────────┤
│  [할일목록 ○]  [카테고리 ○] [프로필 ●] │

```

## 9. 회원 탈퇴 확인 모달
